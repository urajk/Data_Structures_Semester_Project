This project features a showcase of most data structures and algorithms, implemented from scratch in C# by the professor. 
This custom library is then used by me in order to meet all the project's requirements.

Features :
  - Basic Tokenization
  - Basics of load balancing (Query Router)
  - Introduction and implementation of a File Recursion system using a custom Tree library (CTree)
  - Search, Filter and basic analysis of a topic dataset

Hardest Part
  - Within the Tree Recursion system, we were required to use not the prebuilt c# library but the custom one the professor made. This was a problem because we had to display the tree on screen and that can only happen through the built in libraries. Thus we had to first implement the tree using the custom library and then use that custom library to create an equivelent tree using the C# library.

Result
  - The fact that we were provided a custom library contributed in my personal understanding of the deeper code of every data structure. Concepts like the indexer propert used in arrays or the yield operator were particularly interesting.
